## By desired outcome

- **I need a useful result quickly:** [thirty-minute start](START-HERE.md).
- **I need to define one API:** [Meaning-and-Authority Brief](api-meaning-and-authority-brief.md).
- **I am building an MCP server or agent tool:** [Agent-Ready Capability Brief](agent-ready-api-and-mcp-capability-brief.md).
- **I need to choose the interaction type:** [decision guide](api-event-workflow-decision-tree.md).
- **I am worried about duplicates or timeouts:** [Idempotency Matrix](idempotency-and-outcome-test-matrix.md).
- **I am changing a contract:** [Compatibility Evidence Matrix](compatibility-evidence-matrix.md).
- **I need evidence after an incident:** [Outcome Evidence Map](outcome-evidence-map.md).

## By role

- **Developer or API designer:** start with the Meaning-and-Authority Brief,
  then the OpenAPI Implementation Brief and recovery tools.
- **Architect or platform leader:** start with the decision guide, ownership
  card, compatibility matrix, and capacity matrix.
- **Security or governance reviewer:** start with authority, delegation,
  prohibited behavior, evidence, and revocation.
- **Operations or support:** start with errors, unknown outcomes, idempotency,
  observability, and reconstruction.
- **Product or business owner:** complete the capability outcome, consumer
  promise, accepted endings, and change authority before reviewing endpoints.

Use [Role-Based Paths](ROLE-BASED-PATHS.md) for developer, architect, manager,
and executive journeys.
