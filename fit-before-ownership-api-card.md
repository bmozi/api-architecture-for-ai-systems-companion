## 2. Complete options

Include credible versions of:

- current path or do nothing;
- buy/provider API;
- assemble/integrate;
- build; and
- buy to learn, build for the destination.

Reject an option that fails a non-negotiable requirement. Do not rescue it with
a lower ownership estimate.

## 4. Seam ledger

For each viable option, record glue code, policy wrappers, data translation,
error repair, compatibility adapters, manual queues, observability overlays,
and migration work. These seams belong to that option's architecture and cost.

## 5. Continuing ownership ledger

Record who owns consumer compatibility, identity, support, monitoring,
incident response, provider change, compensating integration, migration, and
exit for each viable option.

## 6. Bounded experiment

Test one representative capability and unhappy path against viable options.
Include authorization denial, duplicate request, provider failure,
compatibility change, and evidence reconstruction.
